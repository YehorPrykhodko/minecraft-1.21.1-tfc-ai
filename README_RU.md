# TFC Wildlife AI Remaster — пакет для Codex Cloud

Этот архив — **начальный репозиторий для переписывания мода**, не готовый мод и не восстановленные исходники. Исходные Java-файлы прежней реализации в доступных материалах отсутствуют. В `legacy/` находятся старые **скомпилированные** JAR, а в `docs/legacy_api.txt` — результаты `javap` (сигнатуры классов и методов, не исходный код).

## Куда смотреть

1. `TASK_FOR_CODEX_RU.md` — полное задание для Codex.
2. `AGENTS.md` — постоянные правила проекта; Codex должен учитывать их при работе.
3. `docs/BEHAVIOR_SPEC_RU.md` — желаемое поведение животных.
4. `docs/ARCHITECTURE.md` — как избежать конфликтов между ИИ и навигацией.
5. `docs/REPRODUCTIONS.md` — подтверждённые ошибки из логов.
6. `tests/acceptance_cases.json` — сценарии для автоматических тестов.
7. `legacy/wildlife-ai-324.jar` — последняя диагностическая версия, **только для анализа, не для бинарного патчинга**.
8. `logs/` — отфильтрованные журналы событий Wildlife AI без общего лога загрузки игры.

## Использование с Codex Cloud

1. Распаковать архив и загрузить **содержимое папки** `wildlife-codex-starter` в новый приватный репозиторий GitHub.
2. Открыть `https://chatgpt.com/codex`, подключить репозиторий и облачное окружение.
3. Отправить Codex задание из `TASK_FOR_CODEX_RU.md` либо краткий стартовый запрос в конце этого README.
4. Настроить окружение на **Java 21, Minecraft 1.21.1, NeoForge 21.1.235, TFC 4.2.7** и совместимую версию TaCZ 1.1.8. Не обещать сборку, пока Gradle реально не пройдёт.
5. Для интеграции с локально изменённым TFC v18 использовать **отдельный JAR пользователя** (не хранить крупный сторонний JAR в публичном GitHub-репозитории).
6. После получения нового сборочного JAR вручную проверить поведение в Minecraft и прислать отфильтрованный `latest.log`.

**Важно:** в исходном моде файл `META-INF/neoforge.mods.toml` объявляет обязательные зависимости `tfc` и `tacz`. Не удалять зависимость от TaCZ молча: требуется сохранить звук/обработку выстрелов либо документировать иной способ интеграции.

## Быстрый запрос для Codex

> Прочитай AGENTS.md, TASK_FOR_CODEX_RU.md и все docs/. Это проект чистого переписывания TFC Wildlife AI Remaster. Проведи аудит JAR и логов, создай настоящий исходный Gradle/NeoForge Java-проект с тестируемой архитектурой принятия решений. Начни с инвариантов для гризли и гиен, затем реализуй один централизованный планировщик намерений и навигации. Не патчь байт-код старой сборки. Выполни тесты и Gradle-сборку, а если окружению не хватает TFC или TaCZ — укажи конкретно, что требуется.
