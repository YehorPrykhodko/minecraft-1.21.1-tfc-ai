Общие подсистемы: восприятие, зрение/слух, память, голод, энергия, здоровье, страх, личность/агрессивность/смелость, выбор риска, естественная добыча, стая, помощь при нападении, родительство и защита детёнышей, звуки и сон, устойчивый путь и единый арбитр. Разные мотивы (голод, нападение на животное, защита потомства, удержание позиции) независимы; только один итоговый Decision/tick.

Согласованные важные правила:
- Экстремальный голод может побеждать обычный страх/осторожность, но не критическую травму/смертельную угрозу.
- Гиены, в стае и поодиночке, НЕ начинают неспровоцированную охоту при >=2 подтверждённых игроках, при любом размере стаи. С одним игроком — стая оценивает HP игрока, численность/боеспособность гиен; голод не причина стайной охоты на человека. Соло гиена — редкая агрессия только при сильном голоде.
- Родитель-хищник с собственными детёнышами защищает радиус, заданный серверным конфигом `offspringDefenseRadius` **отдельно для каждого вида**. Значение 15.0 — только начальный default, не жёсткая константа. При нарушении настроенного радиуса возможна быстрая атака без обязательного рыка.
- Волки удерживают ТЕКУЩУЮ позицию, не постоянную территорию/логово; голод, стая, риск, характер и защита потомства определяют агрессию.
- При нападении на одного волка близкие здоровые взрослые помогают, остальные могут не участвовать по логируемым причинам.
- Нужны реальные звуковые предупреждения, стойка WARN/HOLD_GROUND и отдельная DRIVE_OFF: несколько небольших контролируемых шагов к игроку, остановка перед ним, рыки; никаких melee ударов на этапе отпугивания; прекращать при уходе игрока и обоснованно эскалировать при вторжении. Без тиковых петель/спама звуков.

ОБЯЗАТЕЛЬНО: отдельные серверные конфиг-профили для КАЖДОГО поддерживаемого вида (группа -> вид -> опционально SOLO/PACK): обнаружение/зрение/FOV и слух, дистанция раннего ухода, ЖЕЛАЕМАЯ дистанция отхода и шаг движения, радиус предупреждающей стойки/рыка, радиус начала короткого отпугивания и параметры длины/лимита шагов, радиус защитной атаки, радиус защиты детёнышей (`offspringDefenseRadius`, 15.0 по умолчанию, изменяется независимо по виду; проверить в Minecraft), частота звуков, пороги голода/страха, стайные радиусы. Адекватные стартовые defaults предложить, но считать подлежащими калибровке. Проверить в NeoForge, что сериализация/загрузка настроек реально работает.
