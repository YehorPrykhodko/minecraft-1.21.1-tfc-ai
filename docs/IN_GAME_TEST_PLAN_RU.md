# Ручные проверки Minecraft — пока НЕ выполнены

Четыре автоматических серверных GameTest со стандартным TFC 4.2.7 уже прошли;
их точный охват описан в VALIDATION_RU.md. Таблица ниже остаётся отдельным
планом ручной игровой проверки, включая графику и пользовательский TFC v18.

Использовать отдельный тестовый мир с Minecraft 1.21.1 / NeoForge 21.1.235,
TFC 4.2.7 (сначала официальный, затем v18), TaCZ 1.1.8 hotfix-r3 и Patchouli.
Удалить все старые Wildlife JAR. Сначала убедиться в отсутствии mixin/loading
ошибок в **полном** latest.log, затем включить `/wildlife debug nearest`.

| Проверка | Действие и наблюдаемый результат |
|---|---|
| Загрузка dedicated server | Нет загрузки client-классов; все три mixin применены; активен обработчик TaCZ |
| Спокойный гризли | Подойти с 12 блоков: возможна оценка/предупреждение/отход, не обязательная атака |
| #644 / #776 / #1709 | Спровоцировать бой, приближаться/убегать 30 секунд: proximity/pursuit не отменяют атаку на 1 tick |
| Настоящий испуг | Выстрел вблизи/критическое ранение: FLEE возможен и держится не менее настроенного срока |
| Умеренная усталость | Долгая погоня: объяснимый RETREAT, восстановление stamina, без подмены причины паникой |
| Маршрут | Отступление на открытой местности, затем препятствие/поворот угрозы: стабильная точка, repath с причиной |
| Походка v18 | Взрослые/медвежата: ходьба, атака, бегство, склон/ступеньки/вода; нет подпрыгивания/тряски; сравнить скорость |
| Стая и здоровый игрок | 2–5 взрослых гиен, HP игрока 100%, сильный голод: нет неспровоцированной массовой охоты |
| Стая и ослабленный игрок | HP 69% и ниже: пригодные участники выбирают одну цель; раненый участник уходит |
| Точная граница | HP 70%: новая охота не начинается; HP восстановлен после начала: общая фиксация не дёргается |
| Реальная самооборона | Ударить сытую гиену при 100% HP игрока: разрешена ответная защита и помощь стаи |

| Добыча/детёныши | Голодный хищник охотится на замеченную добычу; медвежонок следует взрослому; взрослый защищает рядом |
| Кошачьи | Средняя дистанция: пауза; игрок смотрит — отход; отворачивается — возможна засада; сближение — удар |
| Зрение/слух | Стена, дальность и поворот влияют; шаги/бег/приземление слышны; далёкий закрытый выстрел не гарантирует панику |
| TaCZ | Реальные выстрелы, отменённые выстрелы, пустой магазин, автоматическая очередь; проверить hotfix API и дедупликацию |
| Сохранение | Копия старого мира: значения сытости/stamina сохранены; перезагрузка/выгрузка чанка не портят NBT |
| Другие системы | Приручение волков, рост, сон v18, сторонние AI-моды; учитывать перечисленные ограничения native brain |
| Нагрузка | 50–100 животных: измерить server tick и частоту createPath, объём логов с debug off/on |

Собирать полный лог загрузки плюс выбранные `[TFC-WILDLIFE]` JSON-строки.
Видеозапись нужна для проверки походки: лог или unit test не доказывают
визуальную плавность. Передавать также версии всех установленных модов.
