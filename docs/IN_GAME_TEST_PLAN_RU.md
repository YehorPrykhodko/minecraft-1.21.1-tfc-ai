# Игровая проверка v4 (pending)

Использовать копию профиля/мира с одним Wildlife v4. Сначала стандартный TFC 4.2.7,
затем отдельный профиль с пользовательским v18. Не смешивать два TFC или два Wildlife.
Серверные автоматические результаты перечислены в VALIDATION_RU; ниже проверки,
которые ещё не выполнялись человеком.

1. Гризли: заметить игрока, остановиться, слышимо предупредить, выполнить несколько
   коротких шагов DRIVE_OFF, остановиться; при уходе игрока не спамить рыками.
   Проверить при медленном приближении, спринте, приседании и движении ±0.5 блока
   у warningRadius. Во время DRIVE_OFF без ATTACK урона быть не должно.
2. Голодная охота без урона; после начала боя наблюдать ≥100 тиков без micro-retreat.
   Отдельно — сильный урон, низкая stamina и несколько выстрелов: возможна реальная
   паника, физическое удаление и выдержанное восстановление.
3. Изменить offspringDefenseRadius независимо для гризли/волка/гиены: 8/15/22.
   Использовать связанную семью (ребёнок spawn egg от взрослого или одна spawn cohort),
   не случайно поставленных соседей. Проверить реальные естественные семьи и старых
   детей неизвестного происхождения. Сопоставить CONFIG и CHILD в журнале.
4. Волки: одиночный сытый/голодный, группа, warning/drive-off, помощь при уроне
   одному участнику; раненый/изолированный участник должен иметь veto.
5. Гиены: 1/2/4 взрослых, здоровый и слабый игрок. Ввести второго игрока в активную
   охоту, затем нанести урон гиене — охота прекращается, защита разрешена.
   Исключить из counts детей и тяжело раненых. Проверить разобщённую препятствием стаю.
6. Кошачьи: пауза, TRACK при отвернувшемся игроке, отсутствие охоты у всех подряд.
   Уйти за стену и дождаться TTL; животное не должно знать новые скрытые координаты.
7. Навигация: стены/тупики, лестницы/склоны, вода (особенно crocodile), узкие проходы.
   Для RETREAT достичь retreatTargetSeparation без кругового выбора недостижимых точек.
8. TFC v18: ночь/день, сон/пробуждение, храп и отсутствие Z; анимации головы, лап,
   ускоренного бега взрослых/детёнышей. Кормление, приручение, выгрузка/загрузка чанка.
9. Настоящий старый мир v2/v3: satiety/stamina, старые настройки, повторная загрузка.
   Конфиг v4 имеет отдельное имя; при необходимости применить migrate_config_v3.py.
10. 20–50 животных, несколько игроков, несколько минут: полный TPS/FPS и размер
    latest.log. Облачный замер только нашего Pre не является проверкой всего сервера.

Ничего включать командой не нужно. Прислать **latest.log** текущего запуска после
воспроизведения и кратко описать действие/вид животного. Сама trace не записывает
имена и адреса; сообщения других модов могут их содержать. Для публичного отчёта
использовать CSV/Markdown анализатора вместо публикации произвольных строк других модов:

```bash
python3 scripts/analyze_trace.py /path/latest.log --output trace-report
```

Не принимать отсутствие находок анализатора за доказательство исправности клиентских
анимаций. При DROPPED_EVENTS или trace_radius_limit сначала учитывать неполноту записи.
